# SOCKS5 模式部署指南（v3.0）

v3.0 起 m61grok 支持类 VPN 体验：电脑/手机配置 SOCKS5 代理指向中继，
即可直接访问板子所在内网的**任意 IP:端口**，无需逐个添加映射、无需新开安全组端口。

## 部署步骤

1. **中继升级**：上传新版 `relay/server.py` 到 VPS 的 `/opt/m61-tunnel/`，
   `systemctl restart m61-tunnel`。SOCKS5 复用 7000 端口，systemd 参数无需修改。

2. **板子固件升级**：重新编译烧录（`./flash.sh`）。新协议消息
   `OPENX/AUTHX` 需要板端 v3.0 配合；旧板子连上新中继后 SOCKS 会失败（映射端口不受影响）。

3. **客户端配置**（任选其一）：
   - 浏览器插件（SwitchyOmega 等）：SOCKS5 代理 → `<vps-ip>` 端口 `7000`，
     用户名随意、**密码 = 隧道 token**
   - curl 测试：`curl --proxy "socks5://user:<token>@<vps-ip>:7000" http://192.168.1.100:8080/`
   - 手机：任意 SOCKS 客户端 App，同上

4. 配好后在浏览器直接访问内网地址（如 `http://192.168.1.100/`）即可。

## 安全设计

- 认证：SOCKS5 RFC1929 用户名/密码，**密码即隧道 token**（32 位随机串）
- 目标白名单：**仅允许私网目标**（10/8、172.16/12、192.168/16、127/8），
  防止你的 VPS 被当作开放代理滥用；域名目标默认拒绝
- 并发：板端槽位 8 条（浏览器并发多页面够用）

## 已验证

- SOCKS5 认证（正确/错误密码）、私网目标访问、公网目标拒绝、
  v2 映射端口回归全部通过（本地 fake_board 全链路测试）
